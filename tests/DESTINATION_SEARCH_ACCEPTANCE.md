# Existing global destination search — focused fix

Pfew already uses Photon at `https://photon.komoot.io/api/`, backed by OpenStreetMap, with `city-timezones` as a fallback. Google Places (`GOOGLE_PLACES_API_KEY`) and browser Maps (`NEXT_PUBLIC_GOOGLE_MAPS_API_KEY`) belong to separate existing discovery/map features; neither is used or activated by destination autocomplete. Photon needs no key. Environment values were not printed or modified.

Live evidence: the old eight-result request put Kyoto at candidate 13 for “京都”. Duplicate OSM objects consumed slots; the adapter discarded city/county/district context; all provider results preceded local fallback without destination relevance ranking. There was no country restriction or city-only provider filter. `lang=en` chooses display labels, not a country/query-language restriction. A real Photon romanization gap was reproduced for Koh Phangan versus Ko Phangan.

Changed `lib/worldwide-locations.ts`, `lib/location-search.ts`, `app/api/locations/route.ts`, `components/location-picker.tsx`, two search-scope props in `components/forms.tsx`, and scoped option sizing in `app/globals.css`. `lib/geographic-location.ts` / `lib/location-types.ts` preserve supplied OSM identities in an optional extension of existing geographic identifiers; all prior four-field geographic IDs and city IDs still resolve. No Google/OSM provider IDs or coordinates are invented for manual entries.

Destination fields request all geographic layers (country, state, county, city, district, locality, other), excluding only house/street layers. General booking/activity place inputs retain broad searches. Fetch at most 30 candidates, rank geographical/name matches, deduplicate OSM objects, and show up to 12 options. Preserve Photon ranking across different scripts. Add district/city/county/state/country context and provider type when labels collide. A bounded Ko spelling retry is used only for unmatched Koh destination queries; it merges real provider results with a six-second total deadline.

The picker debounces, aborts superseded requests, caches successful responses briefly, retains existing server fetch caching, supports short non-English names, and keeps lists closed after Escape/blur. Keyboard selection scrolls the active result into view, IME composition is respected, status/help associations are explicit, and touch options have 44px targets. Existing multiple selections and manual named-coordinate/map-pin fallback are preserved. Manual requests cannot overwrite a newer selection.

Validated live with Nairobi, Hallstatt, Koh Phangan, Torres del Paine, Patagonia, São Tomé, 京都, 津, เกาะพะงัน, Victoria, Japan, Yellowstone National Park, and Rarotonga. A transient Yellowstone timeout was reported honestly and a later live retry succeeded. Kyoto and Ko Pha-ngan are now available in the visible set. Short/ambiguous names still require country/region context when many real places share them.

Focused verification passed: lint, TypeScript, production build; 23 related unit/database/form tests; six desktop/mobile browser checks for keyboard/touch selection, multiple independent inputs, caching, Escape during requests, error feedback and manual validation. New files include `tests/browser/location-search.spec.tsx` and its isolated fixture; Playwright registration was extended. Browser tests use mock public search results, never actual trip mutations. Full regression checks are repeated with the subsequent draft foundation.

No new provider, key, billing, schema or service is needed for this fix. Photon supports broad worldwide geographic search, subject to OSM naming/index coverage; countries/regions use a representative point for timezone derivation. The public demo has fair-use throttling and no availability guarantee. Keep attribution and caches; if future traffic exceeds its limits, evaluate hosting the same Photon service separately before considering a provider replacement. See [official API documentation](https://github.com/komoot/photon/blob/master/docs/api-v1.md) and [demo usage terms](https://github.com/komoot/photon#demo-server). No deploy, push or merge was performed.
